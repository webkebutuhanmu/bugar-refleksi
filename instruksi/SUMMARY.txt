🚀 CARA MENGGUNAKAN:

OPSI 1: PHP Built-in Server (Tercepat)
---------------------------------------
1. Buka terminal/command prompt
2. cd ke folder bugar-refleksi
3. Jalankan: php -S localhost:8000
4. Buka browser: http://localhost:8000

OPSI 2: XAMPP/WAMP
------------------
1. Copy folder bugar-refleksi ke htdocs (XAMPP) atau www (WAMP)
2. Start Apache
3. Buka browser: http://localhost/bugar-refleksi

OPSI 3: Production Server
-------------------------
1. Upload semua file ke server (via FTP/cPanel)
2. Set permissions: folders 755, files 644
3. Akses via domain
