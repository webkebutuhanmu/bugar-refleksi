┌─────────────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────────────┘

   • Extract file bugar-refleksi.zip
   • Pastikan struktur folder tetap utuh

┌─────────────────────────────────────────────────────────────────┐
│  2. PILIH METODE INSTALL                                        │
└─────────────────────────────────────────────────────────────────┘

   METODE A - PHP Built-in Server (PALING MUDAH):
   ──────────────────────────────────────────────
   ① Buka Terminal/CMD
   ② cd bugar-refleksi
   ③ php -S localhost:8000
   ④ Buka browser: http://localhost:8000
   
   ✅ Keuntungan: Tidak perlu install XAMPP
   
   
   METODE B - XAMPP/WAMP:
   ──────────────────────
   ① Copy folder ke: C:\xampp\htdocs\
   ② Start Apache di XAMPP
   ③ Buka browser: http://localhost/bugar-refleksi
   
   ✅ Keuntungan: Lebih mirip production server

┌─────────────────────────────────────────────────────────────────┐
│  3. UPDATE KONTAK (PENTING!)                                    │

🐛 TROUBLESHOOTING CEPAT:

❌ ERROR: "Page not found"
   ✅ Solusi: Cek path folder. Harus di root folder saat run php -S

❌ ERROR: CSS tidak muncul
   ✅ Solusi: Cek path di index.php. Pastikan benar:
      <link href="assets/css/style.css">

❌ ERROR: WhatsApp tidak buka
   ✅ Solusi: Update nomor di index.php. Format: 628xxxxxxxxxx

❌ Tampilan rusak di mobile
   ✅ Solusi: Clear cache browser. Refresh dengan Ctrl+F5

💡 TIPS PROFESIONAL:

  1. DEVELOPMENT vs PRODUCTION
     Development: Gunakan localhost
     Production: Upload ke hosting + domain
  
  2. BACKUP RUTIN
     Backup semua file setiap minggu
     Simpan di cloud (Google Drive/Dropbox)
  
  3. UPDATE BERKALA
     Update PHP ke versi terbaru
     Update content secara rutin
     Monitor performance
  
  4. SECURITY
     Enable SSL/HTTPS di production
     Set proper file permissions (755/644)
     Update password secara berkala
